
# Speed-Aware OFDMA Resource Allocation: MP2 Pilot and Baselines

COSC 6358 final project, MP2 (feasibility, pilot evidence, baseline). Team: Jack, Abdullah.

All data in this repository is  **synthetic** : it is generated by our own simulator from fixed random seeds. Nothing is measured.

## What the pilot does

One base station serves K = 4 users over N = 64 OFDM subcarriers (B = 1 MHz, total power 1 W, noise density −80 dBW/Hz, carrier 3.5 GHz). Each user has a 6-tap Rayleigh channel with an exponential power delay profile and an average gain between 0 and −20 dB. The base station allocates using channel information measured τ ms earlier; the channel at transmission time follows a Gauss-Markov model with correlation ρ = J0(2π f_D τ). Rates are chosen from the estimate and delivered on the true channel; a subcarrier whose chosen rate exceeds its true capacity delivers nothing (outage).

Baselines (own implementations):

* **static** : subcarrier n goes to user n mod K, equal power. Ignores the channel.
* **sum_rate** : each subcarrier goes to the user with the largest estimated gain, then water-filling (bisection on the water level). Inspired by Jang and Lee (2003).

Each baseline chooses its rate either exactly at the estimated SNR (0 dB margin) or with a fixed 3 dB back-off.

Conditions: perfect CSI (τ = 0), pedestrian (3 km/h, τ = 2 ms, ρ = 0.996), vehicle (120 km/h, τ = 2 ms, ρ = −0.214). 5 seeds × 200 channel drops per condition. The same seed produces the same channel draws in every condition, so conditions differ only in speed and delay.

## Environment

Tested with Python 3.14.0, NumPy 2.5.4, SciPy 1.18.1, Matplotlib 3.11.2, pytest 9.2.0 on Windows (version 10.0.26200), and with Python 3.13 on Linux; both give identical results. See `evidence/environment.txt` (written by the run). Any recent Python 3.10+ with the packages in `requirements.txt` should work.

## Reproduce everything

From the project root:

```bash

python -m venv .venv && source .venv/bin/activate # Windows: .venv\Scripts\activate

pip install -r requirements.txt

bash run_all.sh # macOS/Linux

run_all.bat # Windows (Command Prompt)

```

`run_all.sh` runs, in order:

```bash

python scripts/run_pilot.py --config config/pilot.json # data/raw/*.csv, evidence/run_log.txt, evidence/environment.txt*

python scripts/summarize.py # results/summary.csv, results/summary_by_seed.csv

python scripts/plot_pilot.py # results/fig_pilot_comparison.png

python scripts/check_correlation.py # results/correlation_check.csv

python scripts/verification_table.py # results/verification_table.csv

python -m pytest -v tests # 16 tests, output saved to evidence/pytest_output.txt

```

Total run time is a few seconds. **Expected key numbers** (mean across 5 seeds, `results/summary.csv`):

| Condition         | sum_rate, 3 dB back-off: delivered sum rate | outage |
| ----------------- | ------------------------------------------- | ------ |
| Perfect CSI       | 5.154 Mbps                                  | 0.00%  |
| Pedestrian 3 km/h | 5.147 Mbps                                  | 0.31%  |
| Vehicle 120 km/h  | 2.808 Mbps                                  | 41.44% |

If you get these values, the pilot is reproduced.

## Folder layout

```

config/pilot.json experiment settings and seeds

src/ofdma/channel.py multipath channel, Doppler, aging (rho = J0)

src/ofdma/allocators.py static and sum-rate baselines, water-filling

src/ofdma/metrics.py planned/delivered rate, outage, Jain index

src/ofdma/sim.py one condition x one seed -> raw rows

scripts/ run, summarize, plot, checks

tests/ hand-checked cases (T1-T11) and invariants

data/raw/ raw pilot output, one CSV per condition and seed (see data/raw/FIELDS.md)

results/ summaries, verification table, correlation check, figure

evidence/ run log with UTC timestamps, environment, pytest output

report/ MP2 report

CONTRIBUTIONS.md who did what

```
