# Speed-aware OFDMA

COSC 6358: resource allocation under outdated channel information.
Python environment only; implementation will follow the proposal.

## Setup

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Dependencies: NumPy for simulation, SciPy for Bessel functions and quantiles,
Matplotlib for plots, and pytest for tests.
